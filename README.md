# Screen Translator

โปรแกรม Windows สำหรับแปลข้อความบนหน้าจอ และเสียงจากคอมพิวเตอร์หรือไมโครโฟน เป็นภาษาไทย ด้วย Google Gemini

> repo นี้เก็บเฉพาะ **ไฟล์ติดตั้ง** สำหรับดาวน์โหลดและอัปเดตอัตโนมัติ ไม่มีซอร์สโค้ด

## ดาวน์โหลด

ไปที่ **[Releases ล่าสุด](../../releases/latest)** แล้วเลือก
- `ScreenTranslator-Setup-x.x.x.exe`: ตัวติดตั้ง (แนะนำ) ไม่ต้องใช้สิทธิ์ admin
- `ScreenTranslator-x.x.x-portable.zip`: แบบพกพา แตกไฟล์แล้วใช้ได้เลย

ติดตั้งแล้ว โปรแกรมจะตรวจหาเวอร์ชันใหม่เอง เมื่อมีอัปเดตจะขึ้นปุ่ม **"อัปเดตเลย"**
ไฟล์ทุกไฟล์ตรวจสอบได้ด้วย `SHA256SUMS.txt` ใน release เดียวกัน

## ใช้ทำอะไรได้
- 📷 **แปลจากหน้าจอ:** กด `Ctrl+Shift+S` แล้วลากคลุมข้อความ
- 🎧 **แปลเสียงเป็นซับไตเติลสด:** จากวิดีโอ เกม คลิป หรือไมโครโฟน
- ✍️ **แปลข้อความ:** พิมพ์หรือวางข้อความ

## ก่อนใช้งาน
- ต้องใช้ **Gemini API key ของตัวเอง** (ขอได้ฟรีที่ https://aistudio.google.com/apikey) โปรแกรมจะถามตอนเปิดครั้งแรก
- ⚠ ภาพ ข้อความ และเสียงที่แปลจะถูกส่งไปยัง Google ถ้าใช้ key แบบฟรี Google อาจนำข้อมูลไปพัฒนาผลิตภัณฑ์ได้ **อย่าใช้กับข้อมูลงาน ข้อมูลลูกค้า หรือข้อมูลส่วนตัว**
- Windows อาจแจ้งว่า "Windows protected your PC" เพราะโปรแกรมไม่มีลายเซ็นดิจิทัล ให้กด *More info → Run anyway*
